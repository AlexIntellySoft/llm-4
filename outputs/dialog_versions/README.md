# Промежуточные прогоны эксперимента с памятью

Эксперимент `dialog` прогонялся несколько раз. Здесь лежат предыдущие версии,
чтобы выводы в отчёте можно было проверить, а не принимать на слово.

## Версии тестового набора (менялись формулировки ходов `longrange`)

| Файл | Что не так |
| --- | --- |
| `exp_dialog_v1_flawed_longrange.json` | Ходы на дальнюю отсылку были написаны как «Напомни, какими были суточные по России?» — вопрос самодостаточен, поиск отвечает на него без всякой памяти. Тест давал 3/3 даже конфигурации `no-memory`, то есть не измерял ничего. |
| `exp_dialog_v2_ambiguous_wording.json` | Исправлено на «Повтори самую первую цифру, которую ты назвал». Модель прочла «цифру» буквально и ответила «2» — первая цифра числа 2 500. Ход измерял формулировку, а не память. |

Итоговая формулировка — «самую первую **сумму**» и «повтори дословно свой самый
первый **ответ**»: в вопросе нет слов темы, поиском такое не вытянуть.

## Версии промпта переформулировки (тестовый набор уже итоговый)

| Файл | Промпт |
| --- | --- |
| `promptv1_rules_only.json` | Исходные 4 правила без примеров |
| `promptv2_fewshot4.json` | 6 правил + 4 few-shot примера |
| `../exp_dialog.json` | 6 правил + 3 примера (убран пример, который модель копировала дословно) |

Сравнение этих трёх прогонов — в отчёте, раздел 4.10.
