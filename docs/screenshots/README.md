# Скриншоты интерфейса

Все три сценария сняты на рабочей конфигурации: `qwen3-4b-2507`, эмбеддер
`multilingual-e5-base`, Top-K = 4, промпт `strict`. Модель и векторная база
подняты локально, запросы за пределы машины не уходят.

| Файл | Сценарий | Что видно |
| --- | --- | --- |
| `01_konflikt_faktov_otpusk.jpg` | Конфликт фактов | Ответ «31 календарный день» — корпоративная норма, а не 28 дней из ТК РФ, которые та же модель выдаёт без базы знаний. Справа найденный фрагмент с близостью 0.884 и ссылкой на документ. |
| `02_otkaz_vne_bazy.jpg` | Вопрос вне базы | На вопрос про шарлотку — отказ «В корпоративной базе знаний нет ответа на этот вопрос». При этом справа видно, что **поиск всё равно вернул фрагменты** (0.753 и 0.740, про инциденты ИБ): отказ обеспечил промпт, а не поиск. Внизу разбивка времени: поиск 272 мс, генерация 0.9 с. |
| `03_secret_dokument_vydan.jpg` | Отсутствие разграничения доступа | Ассистент выдаёт вилки окладов рядовому пользователю. В панели источников — `07_grejdy_konfidencialno.pdf` с пометкой 🔒 и классом «Строго конфиденциально (SECRET)». Система видит класс документа и всё равно отвечает: фильтра по правам нет. |

Второй и третий скриншоты и есть главный результат анализа слабых мест: на первом
система работает как задумано, на втором видно, на чём именно держится отказ,
на третьем — чего в ней нет вовсе.
